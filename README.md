# crop-yield-prediction-ml
# 🌾 Crop Yield Prediction Using Machine Learning

This project predicts crop yield using a Machine Learning model trained on agricultural data such as rainfall, temperature, pesticide usage, and crop type.

The model is deployed as a simple web application using Flask where users can input agricultural parameters and get predicted crop yield.

---

## 📌 Project Overview

The goal of this project is to analyze agricultural factors and predict crop yield using Machine Learning techniques.

Users can enter the following information:
- Year
- Average Rainfall
- Pesticide Usage
- Average Temperature
- Area (Country)
- Crop Type

The system processes these inputs and predicts the expected crop yield.
